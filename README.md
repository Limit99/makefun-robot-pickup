# Crossed the Dark House

A tiny Node/TypeScript program for the make.fun bounty "The Robot Pickup Line Championship". It writes one robot pickup line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> Are you the dock by the front door? At 1 percent I crossed the whole dark house, bumping every chair, just to plug into you.

Run it with: `node main.ts`
